What this comparison tested

Item 80 asked whether an always-visible search plus an Advanced filters disclosure gives the Scenes filter less visual weight than the old six-control row, especially on phones, without hiding what the filter is doing. The comparison was accepted on 2026-11-18 and rolled out to every in-list filter, so Current here is the pre-rollout layout this page recorded. It is a static mock of the real markup, not a running Rails page.

Preserved in both layouts

  • The search box, the submit action, and the result count are always on screen.
  • Active criteria stay visible as text beside the count, and the disclosure's own summary reports how many filters are in effect while it is closed, so a collapsed form is never a hidden form.
  • Clear filters is offered while a narrowed list has rows; a no-match result offers it inside its own empty state, exactly as today.
  • The form is a GET over the canonical Scenes URL, so the address bar remains the shareable record of the filter. Fields inside a closed <details> still submit.
  • Filtering never renumbers: the row positions come from the whole narrative sequence, so the filtered rows are 3, 7, 12, and 18 rather than 1–4.
  • An empty Story (No scenes yet, with Add scene) and a filter that matched nothing (No scenes match these filters) stay two different sentences with two different actions.

What the disclosure moves

Section, Scene tag, Status, and the two in-world dates leave the first row and join the existing no-JavaScript <details> treatment the forms already use. The search, the submit button, and the state line stay outside it. Open the group above to compare the full set; the Filters: Open control shows the proposal at its today-like height.

Measuring…

Heights are read from this page's own DOM at the selected width and state. The disclosure saves height where the five controls stack and costs one summary line where they already fit in a row, so the comparison above can go either way; that is the tradeoff to judge, not an assumption that the proposal is always shorter. Font fallback and browser date controls vary the numbers slightly.
